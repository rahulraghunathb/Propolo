# Frontend

Expo React Native scaffold for the PG rent collection MVP.

## Included

- Expo Router entry setup
- Modular `src/` structure
- SQLite schema, migrations, seed data, repositories, and services
- Placeholder screens for Dashboard and Payments

## Next UI Step

Once designs are ready, we can replace the placeholder screens and wire the existing hooks:

- `useInitializeApp()`
- `useDashboard()`
- `usePayments()`
